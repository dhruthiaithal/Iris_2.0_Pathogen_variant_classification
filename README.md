# Team Iris 2.0
**Domain: AI in bioinformatics**  
Topic:**Pathogenic Variant Classification**: An AI-based machine learning model that analyzes genetic variants using publicly available genomic databases to predict whether a mutation is pathogenic or benign, supporting early diagnosis and precision medicine.

Solution  
- Our solution is an AI driven pathogenic variant classification system designed to assist researchers and clinicians in interpreting genetic variants using publicly available genomic data. Variant annotations from ClinVar, dbSNP, and gnomAD are integrated to create a ML ready dataset suitable for modeling.
- The workflow will begin with data ingestion and filtering, where genetic variants are selected based on clear clinical labels (pathogenic or benign) and variant type (SNPs, SNVs). Variants with uncertain significance or conflicting classifications will be excluded to ensure high quality labels relevant to this problem. From the dataset, biologically meaningful features are extracted. This includes mutation consequence, allele frequency in population databases, conservation scores and functional impact metrics which capture evolutionary, population level signals associated with pathogenicity.
- For classification, we will use modern machine learning models such as gradient boosting algorithms (XGBoost/LightGBM) and neural network based classifiers. These models are chosen for their ability to capture non-linear feature interactions and they would be compared to find the best results. We will also address common mistakes such as class imbalance and overfitting. Model performance will be further improved through hyperparameter optimization across parameter combinations.
- Model performance will be evaluated using clinically relevant metrics, including accuracy, precision, recall, F1 score, ROC-AUC. The final output will be a lightweight, web based prototype built using the ML model deployed using FastAPI as a RESTful backend for real time prediction. Users will be able to input variant level information which returns an output of predicted pathogenicity label, confidence score and feature based explanation. Thus the proposed solution system demonstrates the use of AI to genomic variant interpretation which can work as a data driven decision support tool that can complement existing clinical workflows.
